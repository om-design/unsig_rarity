# unsigned_algorithms Rarity Observatory

Buildless static Site. Serve `dist/` with any HTTP server. Production configuration is in `.openai/hosting.json`.

Run 1 uses the approved inverse-frequency percentage: `100 * (1 - matches / 31118)`. The Total rarity count is the actual intersection of the selected facet values. Zero is excluded from every count. Geometry code is primary; named forms do not affect rarity.

Data rows are `[id, primaryGeometry, propertyCount, publishedColorCluster, properties, referenceGeometry]`. Properties are `[multiplier, color, distribution, rotation]`. Data provenance and project classification choices are explained in the Site's methodology section; detailed capstone artifacts remain in the parent workspace submission packet.

Artwork previews are reconstructed locally from the properties, adapted from the creator's Apache-2.0 rendering notebook. Previews are explicitly labeled, and each result links to the original unsig page. Numerical preview differences are possible; these images do not determine rarity.
